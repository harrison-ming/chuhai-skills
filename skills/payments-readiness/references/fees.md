# 手续费测算方法

`scripts/fees.py` 的算法原文. 只算支付相关费用: 不算税, 不算应用费, 不算利润; Shopify 套餐月费只作参考, 不进合计.

## 1. 公式 (每条路径单独算, 金额按客单价币种)

```
单笔 = 客单价 x (通道费率 + 境外卡占比 x 境外卡附加 + 换汇占比 x 换汇附加) + 固定费
路径月费 = 单笔 x 该路径月单量          (月单量 = 总单量 x 路径占比)
平台附加 = 客单价 x 第三方路径月单量 x 套餐第三方交易费率
提现费   = 每次提现费 x 月提现次数
合计     = 以上已知项之和; 年费 = 月费 x 12; 占比 = 合计 / (客单价 x 总单量)
```

- 用户给了合同费率 (`--gateway 通道:占比:费率+固定费`): 按它算, 不另加境外卡/换汇附加, 标 `[你提供的]`.
- 没给就用 `rates.json` 快照里 `status=verified` 的官方费率; `unverified` 的 (大陆 Shopify Payments, WorldFirst/Payoneer/PingPong/连连/Airwallex 等) **不得作默认值**, 该行记 "查不到", 请用户填.
- 快照覆盖: Stripe 美国/加拿大, PayPal 美国商户/中国大陆账户, Shopify Payments 美国/加拿大各套餐, Shopify 第三方交易费 (Basic 2%, Grow 1%, Advanced 0.6%, Plus 0.2%), 换汇费, 多币种提现费, 争议费. 其他国家/地区的通道费率需用户填写.
- 费率币种与客单价币种不同 (例: 加拿大 Stripe 收 CAD 固定费, 客单价是 USD): 不换算, 该行记 "查不到".
- 境外卡占比: 用户给的优先; 否则按市场分布推算 (账户所在国以外的订单占比), 标 `[推测]`; 都没有记 "查不到".
- 换汇占比: 用户给的优先; 顾客付款币种与结算币种相同时记 0 (写进 "假设").

## 2. Shopify 第三方交易费

- 用第三方通道 (含替代网关) 的订单收取, 启用 Shopify Payments 也不能整体免除 (S15).
- 免收: Shopify Payments / Shop Pay / Shop Pay Installments 付的单; 手动付款与 POS; **以 Shopify Payments 为主通道时的 PayPal 单** (S14 原文). Shopify 里 Shopify Payments 与第三方信用卡网关不能同时开, 所以问卷里有 Shopify Payments 就按 "主通道" 处理.
- 大陆主体多数用不了 Shopify Payments, 所以这项通常整单生效 `[推测]`.
- 非 Shopify 店不收; 平台不确定且没填套餐时不算, 也不猜.
- 退款时: 卡费, 换汇费, 第三方交易费都不退 (大陆店是否适用按比例退回的例外有矛盾, 按不退计).

## 3. 金标准算例 (单测用, 可手算)

大陆主体, Shopify Basic, 客单价 45 USD, 每月 300 单; PayPal 占 40%; 第三方卡通道 3.5% + 0.30 USD 占 60%; PayPal 每月提现 1 次到国内银行.

| 项 | 算式 | 月费 (USD) |
|---|---|---|
| 卡通道 | 180 x (45 x 3.5% + 0.30) | 337.50 |
| PayPal (中国大陆账户跨境 4.4% + 0.30) | 120 x (45 x 4.4% + 0.30) | 273.60 |
| Shopify 第三方交易费 2% | 300 x 45 x 2% | 270.00 |
| PayPal 提现到国内 | 35 x 1 | 35.00 |
| 换汇到人民币 | 没填费率 | 查不到 |
| **合计** | 占月销售额 13,500 的 6.79% | **916.10** (年 10,993.20) |

## 4. 报告写法

- 合计是估算: 写 `[推测] 依据: 你提供的客单价与单量 + 官方费率 (取数日期)`; 每行写出处编号 (附录 B 有网址和日期).
- 只并列展示, **不排 "最省方案", 不推荐通道, 不放推荐/返佣链接**.
- 查不到的项列在 "没算进去的", 不要用经验值补.
- 快照超过 90 天 (`rates_stale`): 提醒 "费率可能已变, 以官方页面和你的合同为准".
