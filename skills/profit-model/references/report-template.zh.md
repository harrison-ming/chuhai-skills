# 报告模板 (中文)

模式 A 由 `pm_report.py` 按本结构生成, 不要手改数字. 模式 C (手算) 按本结构在对话里写. 标题和节名不要改, 第一节必须是 `## 一页看懂`, 附录以 `## 附录` 开头.

```markdown
# <商品名> 利润测算报告

> 测算日期 <YYYY-MM-DD> · 市场 <US> · 售价币种 <USD> · 汇率 1 USD = <7.20> 元 (<日期, 来源>) [你提供的]
> (模式 C 加一行: 手算, 未经脚本校验)

## 一页看懂

- **每单贡献 (广告前) $X**, 占买家实付的 Y% [标签]  (亏损时写 "每卖一单亏 $X")
- 按获客成本 $C, **广告后每单利润 $P** [标签]
- 盈亏平衡 ROAS R, 最高可承受获客成本 $M [标签]
- 底线价 $F (含获客成本 / 不含广告), 目标价 $T (利润率 15%), 建议标价 $T.99 [标签]
- 三情景每单贡献: 保守 / 基准 / 乐观 [标签]
- 最影响利润的输入: <前 3 名> [标签]
- (缺关税时) **未含关税** [查不到]: 关税每增加 10 个百分点, 每单贡献减少 $D [推测] 依据: ...
- 判断: 广告空间 较宽 / 一般 / 偏窄 [推测] 依据: 盈亏平衡 ROAS 与提示线 2 和 3 比较
- 全店每月固定成本 $X, 每月至少卖 N 单才能覆盖 [标签]
- 开张现金 (主路线) 已知项合计 $X [标签]
- 以上都是 "按你给的数字算" 的条件结果, 不是销量或收益预测.

## 1. 你的输入

## 3. 每单账本 (三情景)
(表: 项目 | 保守 | 基准 | 乐观 | 标签; 买家实付 → 净收入 → 各项扣减 → 每单贡献 → 贡献率 → 获客成本 → 广告后每单利润; 下面列与基准不同的假设)

## 6. 定价建议
(底线价, 目标价, 三句理由: 当前价与底线价的差; 要达到目标价改哪两项; 竞品价位置或 "你没给竞品价")
```
