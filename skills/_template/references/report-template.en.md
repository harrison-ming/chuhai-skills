# Report template (English)

Readers are sellers without a technical background. Delete every `<...>` hint.

## Writing rules (for the agent)

- Conclusion first, short plain sentences; numbers with units and currency.
- No evidence codes (E1-E6) or technical words in the body; details go to the appendix. `scripts/check_report.py` has the full list.
- Label every load-bearing claim exactly: `[Verified]` `[Store claims]` `[Third-party]` `[Shown on page]` `[Inferred]` (followed by "Basis: ...") `[Conflicting]` `[Not found]`. Label low rather than high.
- The appendix states `Status: complete` (or partial / failed), matching `status` in `summary.json`.

## Template

```markdown
# <Subject> __TITLE_EN__ report

<sub><URL> · checked on <YYYY-MM-DD></sub>

## At a glance

- <Finding 1> <label>
- <Finding 2> <label>
- <Finding 3> <label>

**Do these 3 things first**
1. <...>
2. <...>
3. <...>

**What this report cannot see**: <one sentence>

## <Check 1, in the seller's words>
<One-sentence conclusion, then 2-4 lines of reasons with labels.>

## What is still unclear
<What could not be retrieved and how to fill the gap. Not found is not the same as absent.>

## Appendix: evidence and sources

| ID | Level | Content | Source | Time |
|---|---|---|---|---|
| E01 | E1 | | raw/<file> | |

- Status: <complete/partial/failed>
- warnings: <raw values>
```

## Short failed report (site unreachable, or nothing could be read)

Use it when `status` in `summary.json` is `failed`. Write and deliver it even for a one-line question; do not just answer in the chat. No technical words in the body.

```markdown
# <Subject> __TITLE_EN__ report

<sub><URL the user gave> · Checked on <YYYY-MM-DD></sub>

## At a glance

- <One-line answer, e.g.: this address does not open right now, so nothing could be checked> [Not found]
- <Where it stopped, e.g.: the site does not exist (maybe a typo) or the network is down>

**What to do next**
1. Check the spelling and retry with the full https:// homepage address.
2. Open it once in a browser; if it loads, send me the address again.

**What this report cannot see**: the site did not open, so nothing was checked.

## Appendix: evidence and sources

- Status: failed
- Failed sources and reasons: <result / note from endpoints>
```

## Fixed ending (after the appendix, unchanged)

```markdown
---

### What this report does not cover

- <What needs a logged-in back office or a browser test.>
- Based on public information only; a snapshot of one day, not due diligence, legal or financial advice.

<sub>Generated by __SKILL_NAME__ (chuhai-skills)</sub>
```
