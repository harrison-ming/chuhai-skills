# 报告模板 (中文)

读者是不懂技术的出海卖家. `radar.py diff` 生成的 `原始数据/diff.md` 已经按本模板排好每一节并带好标签, 你的工作是: 复制成 `原始数据/report.md`, 写完 "需要关注的信号", 把句子改顺. 不要改数字, 不要删标签, 不要删附录和固定结尾.

## 写作要求 (写给 agent)

- 先结论后理由, 短句大白话; 价格带币种, 比例写百分比, 日期写 YYYY-MM-DD.
- 正文不出现技术词 (商品数据接口名, 字段名, 文件名, 证据等级代号), 技术细节放附录. 完整清单以 `scripts/check_report.py` 为准.
- 标签一字不差: `[已核实]` (两次直接读取店铺公开数据的差值) `[页面显示]` (首页, 主题, 应用痕迹, 追踪代码, 多国站点; 以及任何来自网页历史存档的变化) `[店铺自称]` (政策正文的内容) `[推测]` (后跟 "依据: ...", 你的解读都用它) `[有矛盾]` (两个来源冲突, 例如商品没有划线价但首页写着 30% off) `[查不到]` (这次没拿到的). `[第三方说法]` 本技能一般用不到.
- 变化发生在两次快照之间的某个时间, **不写具体哪天改的**, 写 "在 A 到 B 之间".
- 不推断销量, 利润, 广告花费; 价格只代表基础币种的公开标价, 不代表各国结账价; 应用痕迹不等于在用; 支付图标不等于已开通.
- 下架只在 diff.md 里出现下架表时才写; 写着 "不判断下架" 时, 不许写 "下架了 N 款".
- "需要关注的信号" 3-5 条, 每条: 动作 (今晚 / 本周 / 观察) + 依据的事件编号 + `[推测] 依据: ...`.
- 附录写 `完成状态: complete` (或 partial / failed), 与 diff.md 一致; 演示数据的报告保留开头的 "演示数据, 非真实店铺".

## 模板 (变化报告)

```markdown
# <店名> 竞品变化报告

<sub><域名> · 比较 <旧日期> 至 <新日期> · 间隔 <N> 天</sub>

## 一页看懂

- 比较区间: <旧日期> 到 <新日期>. <两份数据各来自哪里>
- 这一期: 上新 <a> 款, 下架 <r 或 未判断> 款, 降价 <d> 款, 涨价 <u> 款, 开始打折 <s> 款 [已核实]
- 最重要的变化:
  1. <变化> <标签> (<事件编号>)
- 下次建议 <日期> 再跑: 对 AI 说 "再看一下 <域名> 有什么变化".

## 价格变动
<全店统一调价 (如有) 一行; 幅度 ≥ 5% 的商品表; "另有 N 款小幅调价, 见 价格变动.csv".>

## 上新与下架
<新品表; 下架表或 "不判断下架" 的原因; 售罄与补货; 新增规格; 上新节奏 (每周数, 近 6 个月对照).>

## 促销节奏
<开始/结束/加深的折扣; 在打折商品占比前后对照; 首页促销文案前后对照 [页面显示].>

## 技术与市场变化
<主题, 应用痕迹, 追踪代码, 币种, 多国站点, 可配送国家数.>

## 政策变化
<每个政策页: 关键条款前后 [店铺自称]; 新增/删除句摘录 ≤ 3 句, 其余在附录.>

## 需要关注的信号
- 本周: <动作> (<事件编号>) [推测] 依据: <哪条变化说明了什么>

## 还有哪些没查清
<不可比的维度, 失败的部分, 存档局限. 拿不到不等于没变.>

## 附录: 口径与数据来源
- 完成状态: <complete/partial/failed>
<快照表, 口径与阈值, warnings 原值, 事件编号对照, 技术词.>
```

基线报告 (只有一份快照) 的标题是 "<店名> 竞品基线报告", 节为: 一页看懂, 当前商品与价格, 技术与市场现状, 政策要点, 需要关注的信号, 还有哪些没查清, 附录. 完成状态 `partial`; 店铺打不开, 被拦或不是 Shopify 店时是 `failed` 短报告, 同样要交付.

## 固定结尾 (附在附录之后, 原样保留)

```markdown
---

### 本报告没有覆盖的

- 两次快照之间的来回变化: 只能看到两个时间点的状态, 中间先降后涨这类变化看不到.
- 需要浏览器才能看到的: 购物车与结账里的优惠, 弹窗, 会员价, 各国实际售价, 广告投放.
- 需要商家后台才知道的: 真实销量, 库存数量, 转化率, 利润, 促销效果.
- 本报告只基于公开信息, 不构成尽职调查或法律意见.

多家对标店一起盯, 历史走势图和定时提醒: https://github.com/harrison-ming/chuhai-skills#进阶

<sub>由 competitor-change-radar (chuhai-skills) 生成</sub>
```
