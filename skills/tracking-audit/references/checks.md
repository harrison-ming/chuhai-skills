# 检查目录

严重度: **高** = 广告平台看不到成交或重复计数, 直接影响出价; **中** = 数据不准或不完整; **低** = 建议; **提示** = 隐私与同意 (不是法律意见). "最高标签" 指公开页面在免费版里最高能给的标签; [有矛盾] / [查不到] 任何时候都可用. 判定由 `scripts/audit.py` 完成, 文案在 `scripts/catalog.py`.

## 隐私与同意 (P, 只是提示)

| 编号 | 检查 | 依据 |
|---|---|---|
| P01 | 看起来面向欧盟/英国 (语言地区, 币种) 却没看到同意横幅的痕迹 | 英国监管 (ICO): 用于广告的追踪需要同意; 欧盟 ePrivacy 指令第 5(3) 条: 在用户终端存取信息需事先同意, 严格必需者除外 |
| P02 | 谷歌同意模式: 是否设置默认值, 是否含第 2 版的两个广告参数 | 谷歌同意模式文档 |
| P04 | 看起来面向美国却没看到 "你的隐私选择 / 不要出售" 类链接 | 加州隐私保护局: 浏览器的退出信号 (GPC) 视为退出出售/共享请求; Shopify 退出页可自动响应 |
| P05 | 面向加拿大: 隐私政策是否写明广告追踪用途与退出方式 | 加拿大隐私专员: 用途讲清, 能马上退出时行为广告可用退出式同意 |
| P06 | 隐私政策是否提到实际在用的广告/分析平台 | - |

同意工具和 Shopify 横幅的识别规则未校准, 看到也只写 [推测]. 同意横幅按访客地区出现, 从中国或北美访问看不到欧盟的行为.
