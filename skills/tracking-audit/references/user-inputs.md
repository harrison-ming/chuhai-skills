# 用户输入: 截图与问答 (U1)

只用于**自家店**. 公开页面跑完后, `audit.py` 在 `原始数据/user-inputs/` 写好 `请你提供.md` (英文 `what-we-need.md`) 和 `answers.template.json`. 把清单用大白话转给用户; 用户不提供也照常出报告, 对应项写 [查不到].

## 1. 先问一句

"你现在在哪些平台投广告? (Meta / 谷歌 / TikTok / Pinterest / Snap / 微软 / 都没有)". 答案决定 T11 和 "没看到" 的严重度.

## 2. 截图清单与点击路径

| 编号 | 让用户提供 | 点击路径 (大白话) | 证明什么 |
|---|---|---|---|
| U1-a | Shopify 客户事件列表 | Shopify 后台 → 设置 → 客户事件: 截整页, 能看到每个应用像素/自定义像素的名字和 "已连接" 状态 | 装了哪些像素, 有没有同平台装了两个 |
| U1-b | Meta 像素概览 | Meta 事件管理工具 → 左侧选你的像素 (数据集) → 概览: 截事件列表, 要能看到每个事件的 "连接方式" (浏览器 / 服务器) | 服务端回传是否在发 |
| U1-c | Meta 测试事件 | 事件管理工具 → 测试事件, 按页面提示打开你的店, 自己下一单测试单 (用测试支付或下单后自己取消退款), 截下 "购买" 事件那一行 | 成交是否同时有浏览器和服务器, 是否标了 "已去重" |
| U1-d | 谷歌分析调试视图 | 先装谷歌的 Tag Assistant 浏览器插件并对你的店开调试; 再打开谷歌分析 → 管理 → 调试视图 (或报告 → 实时), 自己走到下单, 截 "purchase" 事件和它的参数 | 谷歌分析能否收到成交 |
| U1-e | 谷歌广告转化诊断 | 谷歌广告 → 目标 → 转化 → 摘要, 点进 "购买" 转化 → 诊断: 截 "增强型转化" 状态 | 增强型转化是否开启 |
| U1-f | TikTok 测试事件 / 诊断 | TikTok 广告管理平台 → 工具 → 事件 → 选像素 → 测试事件 (或诊断): 截事件来源 (像素 / 事件接口) 和去重提示 | TikTok 服务端与去重 |
| U1-g | 结账附加脚本 | Shopify 后台 → 设置 → 结账: 截 "附加脚本" 一栏, 以及页面顶部是否提示感谢页/订单状态页需要升级 | 旧成交代码是否还依赖已停用的入口 (附加脚本 2025-08-28 起只读; 非 Plus 店 2026-08-26 截止升级) |
| U1-h | 隐私与 Cookie 横幅 | Shopify 后台 → 设置 → 客户隐私: 截横幅显示的地区和 "数据出售退出页" 设置 | 同意横幅地区, 退出页 |
| U1-i | Pinterest / Snap 转化接口 | 对应广告后台的转化接口 (Conversions API) 设置页截图 | 服务端回传与去重 |

提醒用户: **截图前先打码账户名, 邮箱, 手机号, 访问令牌**; 截图只存在自己电脑的 `原始数据/user-inputs/` 里, 报告只引用结论. 下测试单会产生真实订单, 只建议, 不代办.

## 3. 记录到 answers.json

把 `answers.template.json` 另存为 `answers.json`, 按用户实际提供的填写, 没提供的项删掉:

```json
{"ad_platforms": ["meta", "google_ads", "ga4"],
 "items": {"U1-c": {"source": "screenshot", "file": "user-inputs/u1-c.png", "date": "2026-10-26",
                    "ok": true, "ids": {"meta": ["<截图里看到的像素编号>"]}, "note": "购买事件浏览器+服务器, 显示已去重"}}}
```

- `ad_platforms`: meta, google_ads, ga4, tiktok, pinterest, snap, microsoft, reddit; `[]` = 都没投; 不知道就不写这个键.
- `source`: `screenshot` (你看到了截图) 或 `said` (用户口头说的).
- `ok`: `true` 截图显示正常 / `false` 显示有问题 / `null` 看不出.
- `ids`: 截图里能看到的平台编号; 和页面读到的对不上时自动标 [有矛盾].
- 只写截图里真实看到的东西, 看不清就写 `null`, 不要猜.

填好后重跑 `audit.py`, 再按新草稿改报告. 标签规则: 截图 → [已核实] (依据写截图文件名和日期); 编号对不上 → [有矛盾]; 口头 → [店铺自称]; 没提供 → [查不到].
